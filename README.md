# Шиноман

Демо магазина шин и дисков и сайта шиномонтажа. Главная страница содержит калькулятор, раздел `/zapis-na-shinomontazh/` — расписание и форму записи.

## Требования

- Node.js 26.x (`package.json` → `engines.node: ">=26 <27"`).
- npm.

## Локальный запуск

```sh
npm install
npm start
```

Сервер поднимется на http://127.0.0.1:3000/. Каталог шин — http://127.0.0.1:3000/katalog/shiny/, диски — http://127.0.0.1:3000/katalog/diski/, запись — http://127.0.0.1:3000/zapis-na-shinomontazh/.

Для разработки с автоперезапуском: `npm run dev`.

`server.mjs` сохранён как тонкий wrapper: он импортирует `src/server.js`. Основная точка входа — `src/server.js`, приложение Express собирается в `src/app.js`.

## Тесты

```sh
npm test
```

Запускаются unit-тесты конфигурации и интеграционные проверки legacy-сайта, статического allowlist и booking API (`tests/unit`, `tests/integration`).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес прослушивания. Для хостинга обычно `0.0.0.0`. |
| `PORT` | `3000` | Порт. `0` — случайный свободный порт. |
| `PUBLIC_ORIGIN` | `http://127.0.0.1:3000` | Публичный origin без пути, query, hash и завершающего слеша. В `NODE_ENV=production` обязателен и должен быть `https`. |
| `NODE_ENV` | `development` | Режим окружения. |
| `BOOKING_DB_PATH` | `.data/bookings.sqlite` | Путь к базе заявок. |
| `CATALOG_DB_PATH` | `.data/catalog.sqlite` | Путь к снимку каталога. |
| `BOOKING_WEB_ORIGIN` | — | Origin витрины, которой разрешены CORS-запросы к booking API. |

Заявки сохраняются в `.data/bookings.sqlite`. Для размещения на сервере укажите путь к файлу на постоянном диске, а также `HOST=0.0.0.0` и порт, заданный хостингом. В каталоге базы должны храниться и служебные файлы SQLite. API расписания возвращает только время и статус слотов.

## GitHub Pages

Статическую часть можно публиковать из корня репозитория. Для работы записи разместите сервер на хостинге с Node.js и постоянным диском:

1. Укажите в `BOOKING_WEB_ORIGIN` домен витрины с протоколом, без пути и завершающего слеша, например `https://xemmis.github.io`.
2. В `zapis-na-shinomontazh/index.html` заполните `content` у `meta[name="booking-api"]` публичным HTTPS-адресом API с завершающим `/api/`.
3. Для размещения витрины и API на одном сервере оставьте `content` пустым.

Расписание задаётся в `src/booking/schedule.js`. Сейчас запись открыта на 28 дней, слоты идут с 08:00 до 19:00 по Минску с шагом в час. Один адрес, день и час допускают одну заявку. Занятость ведётся в базе этого проекта самостоятельно.

## Каталог и импорт

`katalog/data.json` — демонстрационный набор с условными ценами, изображениями и параметрами автомобилей. Node-сервер отдаёт его до первого импорта. Статическая публикация из корня репозитория показывает этот набор.

```sh
node katalog/catalog-store.mjs путь-к-снимку.json
```

Импорт ожидает полный нормализованный снимок в формате примера. Проверенный снимок записывается одним обновлением в `.data/catalog.sqlite`. На сервере путь можно задать через `CATALOG_DB_PATH` как для импорта, так и для приложения. Если файл некорректный, предыдущий снимок остаётся доступным. После успешного импорта новые цены видны при следующем открытии или обновлении каталога.

- `items`: одна карточка на модель шины или дизайн диска (`id`), один SKU на размер и набор характеристик. Цена (`price`) в копейках BYN за штуку. Для изображения принимается HTTPS-адрес или файл из `katalog/images/`.
- `vehicles`: одна запись на версию автомобиля. У шины сравниваются ширина, профиль, диаметр и минимальный индекс нагрузки. У диска сравниваются диаметр, ширина, PCD, DIA и ET. Индекс скорости и зазоры тормозов следует подтвердить при подключении проверенной базы.
- После получения образцов выгрузок нужен преобразователь в этот формат. Для автоматического изменения сезонных цен нужен регулярный прайс, фид или API поставщика. Планировщик можно подключить к тому же импорту, когда будет известен способ получения актуальных данных. Единоразовая выгрузка обновлять цены сама не сможет.
- В демо можно выбрать вариант и рассчитать сумму для самовывоза. Передача заказов владельцу появится после согласования канала приёма заявок.
