# Шиноман

Портфолио-концепт сайта шиномонтажа. Главная страница содержит калькулятор, раздел `/zapis-na-shinomontazh/` — расписание и форму записи.

## Локальный запуск

Требуется Node.js 24 или новее. В каталоге проекта запустите `node server.mjs` и откройте http://127.0.0.1:3000/zapis-na-shinomontazh/.

Заявки сохраняются в `.data/bookings.sqlite`. Путь можно изменить переменной `BOOKING_DB_PATH`. Для размещения на сервере укажите путь к файлу на постоянном диске, а также `HOST=0.0.0.0` и порт, заданный хостингом. В каталоге базы должны храниться и служебные файлы SQLite. API расписания возвращает только время и статус слотов.

## GitHub Pages

Статическую часть можно публиковать из корня репозитория. Для работы записи разместите `server.mjs` вместе с файлами проекта на хостинге с Node.js и постоянным диском:

1. Укажите в `BOOKING_WEB_ORIGIN` домен витрины с протоколом, без пути и завершающего слеша, например `https://xemmis.github.io`.
2. В `zapis-na-shinomontazh/index.html` заполните `content` у `meta[name="booking-api"]` публичным HTTPS-адресом API с завершающим `/api/`.
3. Для размещения витрины и API на одном сервере оставьте `content` пустым.

Расписание задаётся в `server.mjs`. Сейчас запись открыта на 28 дней, слоты идут с 08:00 до 19:00 по Минску с шагом в час. Один адрес, день и час допускают одну заявку. Занятость ведётся в базе этого проекта самостоятельно.
